# Retail Sales Performance & Analytics Dashboard

An interactive 5-page Power BI dashboard built to analyze retail sales metrics, target achievement, and operational performance.

## Key Features & Metrics
- **KPI Tracking:** Monitored Total Sales ($77.55M), Gross Profit ($1.0M), Average Order Value ($21.45K), and Total Targets ($676.21M).
- **Interactive Visuals:** Dynamic gauge charts, category donut charts, and monthly trend lines across 2017–2020.
- **Deep-Dive Views:** Dedicated pages for Sales Team Performance, Category & Profit Analysis, Reseller & Customer trends, and Strategic Insights.
- **Data Modeling:** Relational schema connecting Products, Salespeople, Regions, Resellers, and Targets using custom DAX measures.
